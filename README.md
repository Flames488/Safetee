# Safetee

A personal safety platform: one-touch SOS, live location sharing, journey monitoring, and trusted contacts.

- `frontend/` — React + Vite PWA
- `backend/` — FastAPI + PostgreSQL + Redis/Celery
- `infra/` — nginx, Prometheus/Grafana, deploy scripts

See `how_to_run.txt` for local dev setup, and each package's own README/`.env.example` for configuration.
